# Loris CLI

## Installation
1. System-wide - use your installer of choice, f.e.:
```sh
uv tool install .
# or
pipx install .
```

2. Locally inside a .env
```sh
pip install -e .
```

## Usage
Use locally via `python loris_cli.py` or `chmod +x loris_cli.py` and `./loris_cli`

Or when you build the package you gain access to the `loris` command which works system-wide.
